# 两层农村住宅设计计划

基于现有两层模型持续细化，目标是尺寸可信、设计可落地、光影真实，并支持电脑和手机浏览。优先美观、实用、耐用和性价比，当前不计算价格。

当前已有四坡灰瓦屋顶、实体檐口、庭院、院门、门廊梁柱、台阶、门窗和排水方案，可编辑 Blender 源文件与 GLB 已同步。原图尺寸按含墙理解；总宽约14.7米仍需复测，外墙24厘米、内墙18厘米、层高3.2米均为暂定。模型用于方案比较，结构与施工节点尚未完成工程复核。

## 本地使用

在项目目录运行：

```powershell
npm ci
npm start
```

打开 <http://127.0.0.1:4179/>。当前模型在 [output/house.blend](output/house.blend) 和 [output/house.glb](output/house.glb)，尺寸参数在 [house_parameters.json](house_parameters.json)。本机运行 `.\rebuild.ps1` 可重建模型；换电脑时需调整脚本内 Blender、Python 路径并安装所需依赖。

尺寸工具地址为 <http://127.0.0.1:4179/viewer/survey.html>。该页不依赖 Three.js 或 Blender；原三维首页仍需 `npm ci`。服务器仍仅监听本机，没有为手机访问开放局域网或公网。

## 数据检查与测试

使用 Node.js 22 或更高版本，先运行 `npm ci` 再执行测试。尺寸校核本身不依赖 Three.js，完整测试需要安装项目依赖；以下命令不启动 Blender：

```powershell
npm run check:dimensions
npm test
node scripts/audit-dimensions.mjs --json
```

校核通过仅表示已覆盖的参数和平面字段一致，**不代表 GLB／Blender 实体、结构、日照或施工验收通过**。调整参数后应重新生成平面，再继续模型重建和实体检查。可选离线浏览器测试的环境要求与局限见阶段文档。

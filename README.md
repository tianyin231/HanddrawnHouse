# 两层农村住宅设计计划

基于现有两层模型持续细化，目标是尺寸可信、设计可落地、光影真实，并支持电脑和手机浏览。优先美观、实用、耐用和性价比，当前不计算价格。

当前已完成可编辑初模、Blender/GLB 导出、平面核对、楼层切换及厨房窗遮挡视图。原图尺寸按含墙理解；总宽约14.7米仍需复测，外墙24厘米、内墙18厘米、层高3.2米均为暂定。当前展示灯光不是日照模拟，屋顶和装修尚未完成。

| 顺序 | 后续工作 | 完成标准 | 状态 |
| --- | --- | --- | --- |
| 1 | 实测与尺寸校核 | 补齐边界、标高、墙厚、门窗、楼梯及邻房尺寸；区分含墙、结构和完成面净尺寸，未知项不冒充实测 | 待推进 |
| 2 | 完整建筑模型 | 补屋顶、外墙、楼板、梁柱、门窗和排水节点；结构做法结合当地设计意见，保留院子挑空和既定动线 | 待推进 |
| 3 | 真实采光与灯光 | 根据具体位置、北向、日期时段及邻房遮挡校核日照；采用真实材质尺度、玻璃和灯具参数，同时检查白天与夜间 | 待推进 |
| 4 | 两层不同装修风格 | 分别确定一层与二层的配色、材质和风格，公共区域衔接自然；先比较方案，再细化选定方向 | 待推进 |
| 5 | 硬装细化 | 地墙顶、门窗收口、厨卫、橱柜、家电、水电、排风与空调按真实尺寸布置，计入饰面厚度和检修空间 | 待推进 |
| 6 | 家具与软装 | 家具、灯具、窗帘等采用可采购或可制作的真实规格；核对柜门抽屉开启、使用空间和通道净宽 | 待推进 |
| 7 | 多种视图 | 完整整体预览必须包含屋顶和墙体；另设未装修、装修后、带尺寸蓝图、楼层及剖切视图，共用同一套尺寸数据 | 待推进 |
| 8 | 真人视角与移动端 | 支持真实眼高、自由行走、上下楼及碰撞；电脑键鼠、手机触控均可用，并在手机和平板核对性能与操作 | 待推进 |
| 9 | 方案复核与经济选材 | 对照实测、图纸与模型检查尺寸、光影、材料和家具；优先常见规格、易维护做法和实惠替代，保留版本对比 | 待推进 |
| 10 | 装修预算 | 方案稳定后再按工程量和当地报价估算，区分必要项与可选项；当前不做单价和总价计算 | 暂缓 |

## 本地使用

在项目目录运行：

```powershell
npm ci
npm start
```

打开 <http://127.0.0.1:4179/>。当前模型在 [output/house.blend](output/house.blend) 和 [output/house.glb](output/house.glb)，尺寸参数在 [house_parameters.json](house_parameters.json)。本机运行 `.\rebuild.ps1` 可重建模型；换电脑时需调整脚本内 Blender、Python 路径并安装所需依赖。

# 两层农村住宅设计计划

基于现有两层模型持续细化，目标是尺寸可信、设计可落地、光影真实，并支持电脑和手机浏览。优先美观、实用、耐用和性价比，当前不计算价格。

当前已有四坡灰瓦屋顶、实体檐口、庭院、院门、门廊梁柱、台阶、门窗和排水方案，可编辑 Blender 源文件与 GLB 已同步。原图尺寸按含墙理解；总宽约14.7米仍需复测，外墙24厘米、内墙18厘米、层高3.2米均为暂定。模型用于方案比较，结构与施工节点尚未完成工程复核。

## 当前进度（2026-10-10）

室内暂沿用 A 配色深化，并保留 B 配色对比；A 不是用户已确认的最终选型。本轮按顺序完成了无需新增现场输入的尺寸图、饰面收口、剩余冰箱/电视柜开合、检修条件清单、材料候选与方案用量，以及画质切换。当前可独立推进的程序与方案项目已完成；项目整体仍需现场测量、最终选型、工程复核和真实设备验收，不能当作施工交付。

- 建筑构造：补入可开关的双扇院门、两层门廊梁柱、院面向明沟找坡、附属间找坡屋面与东北角内落水管。保留三级入户台阶、门廊上楼和附属间前 2 米通道。梁柱尺寸、排水容量、溢流与地下接管仍待复核。
- 日照对比：按邯郸城市参考坐标计算太阳方向，支持日期、北京时间、冬夏预设、北向偏角及邻房遮挡开关；显示四处窗外各 9 个样点的直射情况。南邻房高 3.6 米、北院墙高 2.4 米、东邻房高 6.4 米均为可调假设，邻地标高、体量和坐标未实测；不提供日照时长或室内照度验收结论。
- 材质与收口：调整铺地、屋面及楼板底色，玻璃加入透射与折射参数；补入暂定高 80 mm、厚 12 mm 踢脚线，45 mm 宽门窗套、窗台与卫浴东墙面，按现有洞口让位。材料候选提供瓷砖、地板、面漆和柜体的比较条件，附厂家规格资料入口；未指定采购产品。晴日、傍晚仍是展示灯光，真实灯具选型和光度参数未完成。
- 室内方案：A 为一层暖灰木色、二层浅木米白；B 为一层米白胡桃、二层浅灰蓝。已补一层 L 形厨房与四人餐桌、两层共 8 间卧室家具、4 间卫浴、厅堂和二层起居区；铺地、顶面及示意灯具随楼层组织。默认 A 已同步到 Blender/GLB，B 保留浏览器配色对比，家具与设备规格仍是方案值。烧香间及用途未定小间未擅自改用途，邻房体块只用于浏览器对比。
- 室内查看：提供 17 个房间视角，可切换空房/布置、楼层剖切，并以蓝色区域查看入门、柜前、椅后及卫浴使用范围。新增独立装修尺寸图：整层、单房放大、空房/装修后、使用范围和设备候选接点，可下载 SVG、打印与导出复核 JSON。门扇开启方向、尺寸和家具均来自三维共用数据。
- 开合：两层房门、入户与附属间门、衣柜、厨卫柜门、床头/电视柜抽屉与冰箱上下门共 87 个活动节点；柜内、冰箱内补空腔和搁板，L 形厨房转角留收口。可点击构件或下拉选择，回转遇到墙体、家具、其他活动门板或行走者会停止。检查采用简化碰撞体，不代替五金、把手和成品开角复核。Blender/GLB 保存关闭姿态、独立构件及铰轴信息，动画由本项目查看器提供。
- 自由行走：按 1.65 米眼高从院子或当前房间出发，支持键盘、拖动环看和触屏方向键。沿院坡、三级台阶、折返楼梯通行，有墙体、门柜、家具和栏杆碰撞，不能直接跨越二层挑空。切换视图或退出行走会清理移动状态。
- 设备接驳：可查看 24 个厨卫、冰箱及油烟机候选接点和待确认条件；位置随设备布置计算，并写入模型元数据。给水入口、热水来源、污水出口、配电箱及排烟出口未确定，尚未设计主管、回路规格、防水节点与空调。
- 方案复核：房间页列出家具占位、开合/检修条件及待确认事项；统一清单分为现场待核、选型/用途待定、专业复核、实机待测。地面用量按房间扣墙矩形计算，一层 133.76 ㎡、二层 134.87 ㎡；已建模踢脚线净长分别 98.53 m、94.53 m。不含门洞过门面、门廊、楼梯、院子、附属间及损耗，也未扣饰面厚度或柱突出；只供方案比较，不是采购清单。当前不计算价格。
- 浏览性能：保留按需渲染，新增自动、清晰、流畅三档画质；自动档按视口调整，流畅档降低像素倍率和阴影分辨率。真实手机/平板帧率、发热、内存与触控仍待实机确认。

本轮验证：模型已完整重建；Blender/GLB 回读通过，实体网格 1245 个、GLB 14,158,152 字节；73 项 Node 测试通过，包含尺寸图、饰面洞口让位、用量口径、活动节点回读、逐个开启、碰撞及上下楼往返路线。浏览器检查两层图纸、一层全部房间放大、空房/装修、清单及 SVG/JSON 下载，实际开关新增 10 个活动节点，核对三档画质和 390、768、1440 像素视口，无页面脚本错误；下载 GLB 与本地文件哈希一致。此前院子至二层往返、闭门阻挡/开门通行、触屏方向按钮、17 个室内视角、配色、剖切与日照模式检查保留。视口检查不等于真实手机性能测试，上述结果也不替代现场测量与工程验收。

## 尺寸校核与现场复测工具

已新增独立的[尺寸校核页面](viewer/survey.html)：读取同一套参数和两层平面数据，查看房间含墙尺寸与扣墙估算，记录 42 项现场测量，导出包含房间、门窗的复测清单。首页左侧「尺寸校核与现场复测」进入。

现场记录只保存在当前浏览器，可导入／导出 JSON 转移；**不会自动修改参数、平面或三维模型，也不会将录入记录视为已验收实测**。当前完成面净尺寸、梁下净空及邻房高度仍需现场补齐。详见[阶段交付与验证边界](docs/stage-01-dimensions.md)。

| 顺序 | 后续工作 | 完成标准 | 状态 |
| --- | --- | --- | --- |
| 1 | 实测与尺寸校核 | 补齐边界、标高、墙厚、门窗、楼梯及邻房尺寸；区分含墙、结构和完成面净尺寸，未知项不冒充实测 | 校核与记录工具已完成；现场实测待补 |
| 2 | 完整建筑模型 | 补屋顶、外墙、楼板、梁柱、门窗和排水节点；结构做法结合当地设计意见，保留院子挑空和既定动线 | 方案实体已补齐主要构件；结构、施工节点与排水能力待复核 |
| 3 | 真实采光与灯光 | 根据具体位置、北向、日期时段及邻房遮挡校核日照；采用真实材质尺度、玻璃和灯具参数，同时检查白天与夜间 | 太阳方向和几何遮挡对比已实现；实测条件、日照时长、照度与灯具参数待补 |
| 4 | 两层不同装修风格 | 分别确定一层与二层的配色、材质和风格，公共区域衔接自然；先比较方案，再细化选定方向 | 暂按 A 深化，B 仍可对比；最终配色待定 |
| 5 | 硬装细化 | 地墙顶、门窗收口、厨卫、橱柜、家电、水电、排风与空调按真实尺寸布置，计入饰面厚度和检修空间 | 可独立完成的饰面、收口、柜体、候选接点及检修条件已完成；主管、回路、防水、排烟和空调需现场条件及选型 |
| 6 | 家具与软装 | 家具、灯具、窗帘等采用可采购或可制作的真实规格；核对柜门抽屉开启、使用空间和通道净宽 | 家具软装及 87 个门柜/家电活动节点已实现；成品规格、五金开角、散热距离和现场净距待核 |
| 7 | 多种视图 | 完整整体预览必须包含屋顶和墙体；另设未装修、装修后、带尺寸蓝图、楼层及剖切视图，共用同一套尺寸数据 | 程序功能完成：整栋、楼层、展开、剖切、空房/装修、单房及可导出尺寸图 |
| 8 | 真人视角与移动端 | 支持真实眼高、自由行走、上下楼及碰撞；电脑键鼠、手机触控均可用，并在手机和平板核对性能与操作 | 程序功能和三档画质完成；视口与模拟触控通过，真实设备性能待测 |
| 9 | 方案复核与经济选材 | 对照实测、图纸与模型检查尺寸、光影、材料和家具；优先常见规格、易维护做法和实惠替代，保留版本对比 | 共用数据复核、材料候选/替代条件、模型用量和待确认清单已完成；实物样板、供应规格、现场尺寸与工程结论待补 |
| 10 | 装修预算 | 方案稳定后再按工程量和当地报价估算，区分必要项与可选项；当前不做单价和总价计算 | 暂缓 |

后续输入按依赖顺序补齐：①边界、墙厚、门窗、地面和邻房实测；②给排水出口及标高、配电、热水、排烟/排风、外机位置；③小间用途、A/B 色板和最终产品说明；④结构、防水、电气及其他施工节点的专业复核；⑤真实手机/平板验收。具体每项“方案已做 / 需补 / 影响”见装修复核页的「待确认」，避免把程序完成等同于现场确认。

## 本地使用

在项目目录运行：

```powershell
npm ci
npm start
```

打开 <http://127.0.0.1:4179/>。当前模型在 [output/house.blend](output/house.blend) 和 [output/house.glb](output/house.glb)，尺寸参数在 [house_parameters.json](house_parameters.json)。本机运行 `.\rebuild.ps1` 可重建模型；换电脑时需调整脚本内 Blender、Python 路径并安装所需依赖。

尺寸工具地址为 <http://127.0.0.1:4179/viewer/survey.html>；装修尺寸与方案复核地址为 <http://127.0.0.1:4179/viewer/design-review.html>，首页「室内方案」内可进入。这两个页面不依赖 Three.js 或 Blender；原三维首页仍需 `npm ci`。服务器仍仅监听本机，没有为手机访问开放局域网或公网。

## 数据检查与测试

使用 Node.js 22 或更高版本，先运行 `npm ci` 再执行测试。尺寸校核本身不依赖 Three.js，完整测试需要安装项目依赖；以下命令不启动 Blender：

```powershell
npm run check:dimensions
npm test
node scripts/audit-dimensions.mjs --json
```

校核通过仅表示已覆盖的参数和平面字段一致，**不代表 GLB／Blender 实体、结构、日照或施工验收通过**。调整参数后应重新生成平面，再继续模型重建和实体检查。可选离线浏览器测试的环境要求与局限见阶段文档。

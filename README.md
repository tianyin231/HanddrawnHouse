# 两层农村住宅设计计划

基于现有两层模型持续细化，目标是尺寸可信、设计可落地、光影真实，并支持电脑和手机浏览。优先美观、实用、耐用和性价比，当前不计算价格。

当前已有四坡灰瓦屋顶、实体檐口、庭院、院门、门廊梁柱、台阶、门窗和排水方案，可编辑 Blender 源文件与 GLB 已同步。原图尺寸按含墙理解；总宽约14.7米仍需复测，外墙24厘米、内墙18厘米、层高3.2米均为暂定。模型用于方案比较，结构与施工节点尚未完成工程复核。
